## 🚀 Quick Start

### Browse Solutions
1. Navigate to the topic folder
2. Open the corresponding `.md` file
3. Read the detailed explanation and code

### Compile & Run Code
1. Copy the C++ code from any `.md` file
2. Save as `.cpp` file
3. Compile: `g++ -std=c++17 filename.cpp -o output`
4. Run: `./output`

### Example:
```bash
# Compile and run Dijkstra's algorithm
cd Graph
g++ -std=c++17 dijkstra.cpp -o dijkstra
./dijkstra
